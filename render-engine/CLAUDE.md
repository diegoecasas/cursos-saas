# teach animado

Proyecto Remotion para lecciones/cursos animados.

## Normas del proyecto

### Infografías y logotipos

Cada vez que una lección o curso necesite infografía o logotipos de marcas/tecnologías,
usar la librería **Simple Icons** para obtenerlos: https://github.com/simple-icons/simple-icons

- Paquete npm: `simple-icons` (SVGs de +3000 marcas, listos para usar como paths en React/SVG).
- Preferir estos iconos sobre generarlos con IA o buscarlos sueltos en internet, para mantener
  consistencia visual y evitar problemas de licencia.
